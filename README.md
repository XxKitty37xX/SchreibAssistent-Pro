# SchreibAssistent Pro

Professionelle Linux-Desktopanwendung für Schriftverkehr und Dokumente.

## Version 0.0.1

Enthalten:
- moderner Dokumenteneditor
- neue, öffnen und speichern
- Ausschneiden, Kopieren, Einfügen
- Rückgängig/Wiederholen
- Wort- und Zeichenzähler
- deutsche Benutzeroberfläche
- erste Grundlage für die weiteren Module

## Start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```
